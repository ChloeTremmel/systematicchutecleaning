SYSTEMATIC CLEANING WEBSITE

Contents
--------
index.html  - The complete website, including its HTML, CSS, and JavaScript.

How to open it
--------------
1. Extract the ZIP archive.
2. Double-click index.html to open the website locally in a web browser.

How to publish with GitHub Pages
--------------------------------
1. Create a new GitHub repository.
2. Upload index.html to the top level of the repository.
3. Open the repository's Settings, then Pages.
4. Select "Deploy from a branch," choose the main branch and /(root), and save.

The site currently uses Google Fonts, so an internet connection is required for
the Manrope and DM Sans fonts to load. All other styling and behavior is included
inside index.html.
